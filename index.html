Preguntas frecuentes

Información clara para clientes que quieren contratar rápido.

¿La web guarda los datos?

En GitHub Pages la web funciona como sitio estático. El formulario prepara la solicitud para continuar la atención por WhatsApp o correo. Si se requiere guardar datos automáticamente, se puede conectar con Google Sheets, Make, Formspree o un webhook externo.

¿Puedo conectar Google Sheets?

Sí. Se puede crear una automatización con Make usando un webhook, Google Sheets y Gmail. Luego se conecta el formulario del sitio para registrar los datos del cliente.

¿El cliente puede agendar?

Sí. El formulario pide modalidad online o presencial, día, fecha y hora tentativa. Luego RedPyme IA 360 confirma la disponibilidad por WhatsApp o correo.
