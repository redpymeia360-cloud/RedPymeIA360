# Configurar Netlify Forms para RedPyme IA 360

1. Publica la web en Netlify.
2. Entra al sitio publicado.
3. Completa el formulario una vez.
4. En Netlify ve a Forms.
5. Debe aparecer el formulario: contacto-redpymeia360.
6. En Form notifications agrega Email notification.
7. Escribe: redpymeia360@gmail.com.

El formulario guardará:
- nombre
- apellido
- WhatsApp
- correo
- tipo de cliente
- plan
- modalidad
- fecha
- hora
- mensaje

Para Google Sheets, usa Make:
Webhook -> Google Sheets -> Gmail -> Webhook Response.
